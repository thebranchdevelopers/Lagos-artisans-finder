# Lagos Artisans Finder

A mobile web application to help visitors find skilled artisans in Lagos, Nigeria. The app provides location-based services to connect users with various types of service providers including electricians, mechanics, plumbers, and more.

## Features

- **6 Artisan Categories**: Washing Machine Repairers, Electricians, Mechanics, Plumbers, Phone Repairers, and Laptop Repairers
- **Location Services**: Real-time distance calculation and travel time estimation
- **Contact Information**: Direct calling and email contact for each artisan
- **Workshop Images**: Visual representation of artisan workshops and services
- **Detailed Profiles**: Experience, specialties, ratings, and contact details
- **Mobile-Optimized**: Responsive design for mobile devices
- **Google Maps Integration**: Get directions to artisan locations

## Technology Stack

- HTML5
- CSS3 (with responsive design)
- Vanilla JavaScript
- Geolocation API
- Font Awesome Icons
- Google Maps Integration

## Getting Started

1. Clone or download the project files
2. Open `index.html` in a web browser
3. Allow location access when prompted for distance calculations
4. Browse artisan categories and find service providers

## Usage

1. **Browse Categories**: Select from 6 different artisan types on the main screen
2. **View Artisans**: See a list of available service providers in each category
3. **Check Distance**: View estimated travel time to each artisan (requires location access)
4. **Contact Artisans**: Call directly or get directions via Google Maps
5. **View Details**: See detailed profiles including experience, specialties, and ratings

## Location Features

- **Distance Calculation**: Shows how far each artisan is from your current location
- **Travel Time**: Estimates travel time based on Lagos traffic conditions
- **Real-time Updates**: Updates distances as you move around the city
- **Google Maps Integration**: Get turn-by-turn directions
